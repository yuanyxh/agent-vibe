# 记忆协议

默认把记忆写入项目，外部记忆服务只作为可选增强。

## 位置

| 内容 | 位置 |
| --- | --- |
| 当前目标与进度 | `.agent/status.md` |
| 决策与回退 | `.agent/decisions.md` |
| 有证据的经验 | `.agent/lessons.md` |
| 长期事实、偏好与约束 | `.agent/memory/` |

## 写入时机

- 关键决策与取舍。
- 用户偏好或纠正。
- 缺陷根因与回归方式。
- 发布结果与已知问题。
- 任务中断时的交接信息。

## 写入规则

1. 一条记忆只写一个事实。
2. 附来源：会话、命令输出、文件或测试。
3. 标注适用范围：仅本项目、本技术栈或可能通用。
4. 与已有条目同义时合并，不重复新增。
5. 被新事实推翻时标注取代关系，不删除历史。

## 检索顺序

1. `.agent/status.md`
2. `.agent/decisions.md`
3. `.agent/lessons.md`
4. `.agent/memory/`
5. 外部记忆服务（若存在）

记忆是线索，不是证据。与当前代码、测试或用户说明冲突时，以当前事实为准。

## 外部记忆

环境提供外部记忆服务时可以同步，但必须：

- 只写脱敏后的通用模式。
- 不写项目名、路径、凭据与业务数据。
- 外部服务不可用时，项目内记忆必须完整可用。

## 晋升

项目内反复验证的模式，按 `protocols/distill.md` 提议进入种子库；未经用户确认不得自动晋升。

## 禁止

- 用记忆覆盖用户当前修正。
- 把一次偶发事件记为通用规律。
- 让记忆成为任务执行的阻塞项。
