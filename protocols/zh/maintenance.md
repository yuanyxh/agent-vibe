# 维护协议

让 agent 环境保持健康，让学习不依赖用户记得主动提出。

## 触发

| 触发 | 条件 |
| --- | --- |
| 报告过期 | `.agent/agent-health.md` 超过 `agent.maintenance_stale_days` 未更新 |
| 变更事件 | 缺陷修复、发布、重构或用户修正产生了新证据 |
| 行为冲突 | agent 忽略规则、调用错误技能或与记忆矛盾 |
| 资产变更 | 新增、删除或重组规则、技能、提示词、钩子或 MCP 服务之前 |
| 定时 | 达到配置的节奏 |
| 用户请求 | 用户要求体检、复盘或整理 |

## 机制类别

| 类别 | 行为 | 降级到 |
| --- | --- | --- |
| `native-hook` | 平台在生命周期事件触发，可注入提醒或接收决定 | `session-scheduler` |
| `session-scheduler` | 平台可在会话存活时按定时器运行提示 | `cloud-automation` |
| `cloud-automation` | 远程 agent 按计划或外部事件运行 | `os-ci-scheduler` |
| `os-ci-scheduler` | 操作系统调度器或 CI 任务调用 agent | `advisory` |
| `advisory` | 契约写明触发条件，由 agent 显式检查 | 无 |

## 模式

- `advisory`：只有契约规则。可靠性最低，不需要平台配置。
- `hook`：平台生命周期钩子注入简短提醒。平台支持时作为默认。
- `scheduled`：平台自动化、操作系统定时或 CI 计划。用于节奏提醒；不要依赖它完成同会话捕获。

项目可以同时使用 `hook` 与 `scheduled`。平台没有钩子时降级为 `advisory`，并在契约中标记降级。

## 状态与节流

只使用 `.agent/.maintenance-state` 一个状态文件：

```text
last_run: <ISO-8601>
last_reminder: <ISO-8601>
pending: learn | steward | sandbox
```

- `agent.maintenance_stale_days` 默认 7。
- 24 小时内不重复提醒。
- 每个会话最多提醒一次。
- 阻塞式停止需要显式开启；开启后每个会话最多阻塞一次，同一待办不重复阻塞。
- 成功执行后清空 `pending` 并更新 `last_run`。

## 钩子契约

- 2 秒内完成；禁止联网。
- 对项目内容只读：不修改项目文件、不提交、不外发数据；仅可为节流更新 `.agent/.maintenance-state`。
- 幂等：重复调用得到相同结果。
- 报告新鲜时不输出；过期时只输出一行简短提醒。
- 出错或超时退出码为 0，把失败追加到 `.agent/agent-health.md`，不阻塞会话。
- 输出中不得包含密钥、个人路径或生产地址。

## learn 触发

- 缺陷修复、发布、重构或用户修正后运行。
- 只有出现新证据才运行；没有新事实就不记录。
- 发现写入 `.agent/lessons.md`、`.agent/backlog.md` 或重构任务；不自动重构。

## steward 触发

- 报告过期、行为与资产冲突或计划变更资产时运行。
- 检查提示词、规则、技能、记忆、钩子、MCP、子代理、命令、插件与环境。
- 不检查业务代码腐化；交给 `learn` 或 `review`。

## sandbox 触发

- 集成测试或端到端验证可能触碰共享或生产系统之前运行。
- 需要模拟外部服务、凭据、设备或操作系统时运行。
- 无法隔离时阻塞，并明确列出不可验证项。

## 降级

| 缺少能力 | 首选动作 |
| --- | --- |
| 原生钩子 | 会话调度或契约提醒 |
| 会话调度 | 云自动化或操作系统/CI 计划 |
| 云自动化 | 操作系统/CI 计划 |
| 任何自动机制 | 契约规则 + 显式调用 |
| 隔离运行时 | 进程级隔离，使用临时数据与端口 |
| 进程级隔离 | 阻塞并列出不可验证项 |

机制不存在时不得声称自动触发；在契约中标记 `degraded`。

## 安全

- 维护与隔离不得使用生产数据、凭据或端点。
- 删除一律移动到废纸篓或归档；禁止原地删除。
- 修改规则、技能、记忆或提示词前必须取得用户确认。
- 报告中不写密钥、个人路径、主机名或内网地址。

## 验证

- 报告新鲜时无提醒；过期或缺失时恰好提醒一次。
- 在节流窗口内重复调用不产生第二次提醒。
- 移除钩子后契约出现明确缺口，而不是静默失败。
- 定时任务试运行能显示预期节奏与上次运行状态。
- 维护执行后，`last_run` 与 `pending` 与实际结果一致。

## 禁止

- 自动修改 agent 资产或提交变更。
- 把“已提醒”报告成“已完成检查”。
- 未经用户显式开启就使用阻塞钩子。
- 在维护或隔离文件中保存生产数据或凭据。
