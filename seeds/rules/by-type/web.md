# Web 规则

## WEB-01 构建可复现

**规则**：依赖锁定文件入库，构建命令在干净环境可重复得到相同产物。

**禁止**：依赖浮动版本而不锁定。

**验证**：清理缓存后重新安装与构建成功。

## WEB-02 边界校验

**规则**：所有来自浏览器、URL、存储与第三方的数据在进入业务逻辑前校验。

**禁止**：信任客户端传入的权限、价格、身份等关键字段。

**验证**：构造非法输入时被拒绝且有明确错误。

## WEB-03 权限一致

**规则**：前端隐藏入口只是体验优化，服务端必须独立校验权限。

**禁止**：以界面不可见作为权限控制。

**验证**：直接调用接口时越权请求被拒绝。

## WEB-04 性能预算

**规则**：首屏体积、关键路径耗时与请求数量有可度量上限，超限时先优化再发布。

**禁止**：无预算地持续增加依赖与资源。

**验证**：构建产物报告与画像中的预算对比。

## WEB-05 可访问性基线

**规则**：交互元素可键盘操作，表单有标签，图片有替代文本，颜色对比满足画像要求。

**禁止**：只用颜色或鼠标事件表达关键信息。

**验证**：键盘走查与自动检查通过。
