# 维护规则

## MNT-01 变更后捕获

**规则**：缺陷修复、发布、重构或用户修正后，带具体证据运行 `learn`；没有新事实就不记录。

**禁止**：记录猜测；重复已有教训。

**验证**：每条新教训都能对应到命令、文件或用户表述。

## MNT-02 周期性 agent 体检

**规则**：体检报告超过配置间隔、agent 行为与规则或技能冲突、或计划新增/删除规则、技能、提示词、钩子、MCP 服务之前，运行 `steward`。

**禁止**：自动修改规则、技能、记忆或提示词；未经确认删除资产。

**验证**：报告有证据，每项已应用的变更都有用户确认。

## MNT-03 E2E 前隔离

**规则**：集成测试或端到端验证之前，用 `sandbox` 创建隔离环境；不得对生产或共享预发环境运行。

**禁止**：使用生产凭据或数据；无法隔离时伪造 E2E。

**验证**：隔离报告包含隔离端点、合成数据、通过的 E2E 与拆除结果。

## MNT-04 用户修正优先

**规则**：记忆、规则或旧结论与用户当前修正冲突时，先停下确认，再把旧条目标记为 superseded。

**禁止**：用记忆覆盖用户当前表述。

**验证**：决策记录包含该修正与被替代的条目。
