# CLI 规则

## CLI-01 输出可管道

**规则**：正常结果写标准输出，诊断与错误写标准错误；支持非交互环境。

**禁止**：把日志与结果混在同一输出流。

**验证**：重定向标准输出后结果可被解析，错误仍可见。

## CLI-02 退出码有意义

**规则**：成功为 0，可预期失败使用稳定的非零退出码并在文档中列出。

**禁止**：失败时返回 0。

**验证**：各类失败场景的退出码与文档一致。

## CLI-03 非交互可用

**规则**：所有交互选项都有对应参数或环境变量，可在 CI 中无提示运行。

**禁止**：必须人工输入才能完成核心流程。

**验证**：在无终端输入的环境执行核心命令成功。

## CLI-04 可中断与可恢复

**规则**：长时间操作响应中断信号，并留下可恢复状态或明确的部分结果。

**禁止**：中断后留下无法判断完整性的产物。

**验证**：中途终止后再次执行行为可预期。
