# agent 环境能力

## 目标

让 agent 自己的环境可信：提示词、规则、技能、记忆、钩子、MCP 服务、子代理、命令、插件，以及它们依赖的工具。

## 范围

| 资产 | 检查内容 |
| --- | --- |
| 平台与模型 | 平台、模型、上下文窗口、权限、沙箱、会话存储 |
| 提示词与契约 | 契约、常驻块、未解析占位符、互相矛盾的指令、过期的项目描述 |
| 规则 | 分层、作用域、重复、冲突、过期、未被引用、预算超限 |
| 技能 | 触发描述、重叠、重名、缺失资源、长期未使用、引用有效性 |
| 记忆 | 索引大小、重复或矛盾条目、缺失来源、过期作用域、归档完整性 |
| 钩子与自动化 | 已配置钩子、失效钩子、静默失败、重复计划、超时 |
| MCP | 服务可用性、工具重叠、认证过期、权限范围、密钥泄漏、未使用服务 |
| 子代理、命令、插件 | 重复、孤儿条目、断引用、来源、许可证、维护状态 |
| 环境 | 运行时与工具链漂移、缺失探测、过期环境记录 |
| 证据 | git 历史、状态、决策、教训、记忆、会话记录、配置文件 |

## 腐化信号

| 信号 | 例子 |
| --- | --- |
| 矛盾 | 两条规则对同一情境给出不同行为 |
| 陈旧 | `review_by` 过期、版本过旧、项目描述已不成立 |
| 重复 | 两个技能覆盖同一触发；两条记忆陈述同一事实 |
| 断引用 | 规则指向不存在的技能或文件；技能资源缺失 |
| 预算超限 | 常驻契约超预算；技能清单截断描述 |
| 静默失败 | 钩子或 MCP 服务失败但没有暴露错误 |
| 记忆冲突 | 记忆与代码、决策或用户当前修正矛盾 |
| 重复修正 | 同一用户修正或缺陷反复出现，却没有新教训或规则 |
| 死资产 | 规则或技能从未被引用、调用，或已被完全替代 |
| 泄漏 | agent 资产中出现密钥、个人路径、主机名或内网地址 |

## 证据来源

- git log 与 diff：重复修复、回退的决策、没有决策记录的频繁改动。
- `.agent/status.md`、`decisions.md`、`lessons.md`、`backlog.md` 与 `memory/`：结论、替代关系、未解决项。
- 平台暴露的会话记录：重复提示、被忽略的指令、错误的技能选择。
- 钩子、MCP 与平台配置：注册、权限、超时、最近错误。
- 确定性检查：行数、重复 ID、断链、过期日期、密钥模式。

## 输出

写入 `.agent/agent-health.md`，按时间戳分节：

- 已检查范围与跳过项及原因。
- 按严重度排序的发现：阻塞、高、中、低。
- 每条发现包含证据、影响、建议与置信度。
- 建议动作：保留、合并、拆分、弃用、移到废纸篓、新增。
- 已应用且经用户确认的变更；否则列出明确待办。

延后工作写入 `.agent/backlog.md`；确认的决策写入 `.agent/decisions.md`。

## 应用策略

- 先提议，用户确认后再应用。
- 删除的资产移到废纸篓或归档；禁止原地删除。
- 不通过本能力修改业务代码。
- 不自动提交。
- 用户修正记忆或规则时，以当前表述为准，把旧条目标记为 superseded。

## 边界

- 本能力不审计业务代码的架构、反模式或死代码；交给 `learn` 或 `review`。
- 生成前的初始资产盘点属于 `capability/agent-assets`；本能力是生成后的周期性体检。
- 开发工具探测属于 `capability/environment`；本能力检查 agent 自身环境与资产是否一致。

## 反例

- 没有检查触发证据就把技能判为未使用。
- 用户已修正后仍把陈旧记忆当作事实。
- 因为规则未被引用就删除，却没有核对平台级加载。
- 审计业务模块，却把结果称为 agent 环境腐化。
