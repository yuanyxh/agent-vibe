# 环境能力

## 目标

换一台机器或换一个 Agent 环境时，先知道“有什么、缺什么、怎么办”，而不是假设工具存在。

## 探测顺序

1. 运行时与版本
2. 包管理器与依赖安装方式
3. 构建、测试、静态检查
4. 版本控制与托管 CLI
5. 诊断、浏览器与自动化
6. 容器、云 CLI 与外部服务

## 判定

| 状态 | 判据 |
| --- | --- |
| 可用 | 命令存在且版本满足项目声明 |
| 部分可用 | 命令存在但版本不足或能力受限 |
| 缺失 | 命令不存在 |

## 处理

- 有等价替代时，优先使用替代并登记差异。
- 需要安装时，说明用途、来源与影响，取得用户确认。
- 验收依赖且无替代时，明确阻塞，不静默跳过。
- 探测结果写入 `.agent/environment.md`，包含时间、命令与结论。

## 禁止

- 把本机路径、版本或镜像地址写成项目默认。
- 因工具缺失而伪造验证结果。
- 未经确认安装全局工具或修改系统配置。
