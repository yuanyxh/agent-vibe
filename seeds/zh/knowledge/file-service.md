# 文件服务

## 问题

安全地接收、保存、分发文件，并控制谁能在什么条件下访问。

## 模式

- **上传**：限制大小、类型与数量；服务端校验真实类型，不信任扩展名。
- **存储**：对象存储优先；文件名使用随机标识，保留原始名称作为元数据。
- **访问**：私有文件通过短期签名 URL 或受控代理访问；下载前校验权限。
- **预览**：图片、PDF、Office 文档按能力选择预览方式；不可预览时提供下载。
- **清理**：孤立文件、过期临时文件与删除请求有清理策略。
- **安全**：禁止执行上传内容；对图片做重编码以去除恶意负载。

## 取舍

| 方案 | 适用 | 代价 |
| --- | --- | --- |
| 本地磁盘 | 单机、小规模 | 扩展与备份困难 |
| 对象存储 | 大规模、CDN | 需要权限与生命周期配置 |
| 数据库存二进制 | 小文件、强事务 | 容量与性能受限 |

## 验证

- 非法类型与超大文件被拒绝。
- 未授权用户无法通过猜测地址下载。
- 删除后不可再访问，关联数据同步处理。
- 上传中断不留下半个文件。

## 反例

- 只校验扩展名。
- 公开桶存放私有文件。
- 用原始文件名作为存储路径。
- 预览服务执行上传内容。
