# 发布

## 目标

任何一次交付都能回答：构建自哪个提交、包含什么、如何安装、如何回退。

## 生成原则

- 版本号规则来自用户与分发渠道约束，不预设。
- 发布说明面向使用者，写变更与影响，不复制提交日志。
- 签名、公证与自动更新属于外部事实，生成前查当前流程。
- 发布动作属于不可逆或外部可见操作，执行前取得用户确认。

## 验证

用同一提交重新构建得到等价产物；按文档完成一次安装与一次回退。
